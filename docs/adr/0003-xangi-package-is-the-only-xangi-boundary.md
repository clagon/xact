# xangi の API を知るのは `xangi` パッケージだけにする

xangi の HTTP エンドポイント、SSE のイベント形式、JSON のスキーマを扱うのは `xangi` パッケージだけにする。他のパッケージには、Session、Turn、Side Chat の状態といったドメイン用語の型だけを渡す。xangi は更新が速く、API や SSE の形が変わりやすい。境界をここ 1 本に絞れば、変更が起きても直す場所は 1 か所で済む。マルチモジュールや Clean Architecture の 3 層構成も検討したが、個人開発の規模では手間に見合わないため採らなかった。
